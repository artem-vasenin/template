# Контекст проекта

## Назначение

Это стартовый Django-проект для разработки «коробочной версии» шаблонных сайтов: общего переиспользуемого решения, которое можно адаптировать и разворачивать для разных сайтов. Конкретные функции, архитектура и способ конфигурации пока не определены; не придумывай их без необходимости.

## Текущее состояние

- Базовый проект Django находится в пакете `core`.
- Сейчас есть только стандартные файлы запуска, настроек, URL-маршрутов и ASGI/WSGI.
- Подключены стандартные приложения Django; из пользовательских маршрутов настроена только админка.
- Настройки читаются через `django-environ`: локальный файл `.env` загружается из корня проекта.
- База данных настраивается через `DATABASE_URL` и `env.db()`; текущая конфигурация рассчитана на PostgreSQL.
- Драйвер PostgreSQL `psycopg` и пакет `django-environ` указаны в `requirements.txt`.
- Пример переменных окружения хранится в `example.env`; сверяй его со `core/settings.py` при изменении настроек.
- `README.md` пока содержит только краткое описание Python/Django/CMS.

## Правила работы

- Перед изменениями изучай существующую структуру и сохраняй принятые в Django соглашения.
- Сначала уточняй или фиксируй в документации значимые архитектурные решения; не добавляй зависимости и приложения «про запас».
- Не помещай секреты и производственные учётные данные в репозиторий. При подготовке настроек для окружений используй переменные окружения.
- Не коммить локальный `.env`; обновляй пример `example.env` без реальных секретов, когда добавляются обязательные переменные.
- Новые функции сопровождай соответствующими тестами и обновлением документации, когда это уместно.
- Поддерживай пользовательский интерфейс и тексты на русском языке, если требования конкретной функции не задают иное.

## Обновление контекста

По мере появления решений добавляй сюда только устойчивые и полезные для следующих задач сведения: назначение компонентов, важные соглашения, команды разработки и проверки, ограничения и принятые архитектурные решения. Удаляй устаревшие указания.
